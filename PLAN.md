# JamMates
## Tech Stack
- FastAPI + Python
- SQLAlchemy (async) + PostgreSQL
- Pydantic v2
- Redis (caching)
- JWT authentication
- Spotify API (spotipy)
- Bandsintown API

## Opis
JamMates to aplikacja dla ludzi, w skrócie którzy kochają muzykę i chcą chodzić na koncerty ze znajomymi.
Łączysz swoje Spotify, aplikacja sprawdza czego słuchasz i na tej podstawie poleca Ci koncerty
w Twojej okolicy. Możesz też założyć Circle ze znajomymi (max 3 osoby) — wtedy znajdywane są
koncerty, które będą pasować do gustu całej grupy, nie tylko Twojego.

Są dwa tryby rekomendacji: "For You" podpowiada koncerty artystów, których znasz i lubisz,
a "Something New?" proponuje kogoś podobnego i nowego.
